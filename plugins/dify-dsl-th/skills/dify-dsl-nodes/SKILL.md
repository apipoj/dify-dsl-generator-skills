# dify-dsl-nodes

ใช้เมื่อกำลังทำงานระดับโหนด ไม่ใช้แทนการเลือกโหมดหรือเทมเพลต

## เริ่มอ่าน

อ่าน [ดัชนีอ้างอิง](references/index.md) แล้วโหลดเฉพาะเอกสารโหนดที่จะใช้ในงานนี้

## ข้อกำหนด

- สร้าง DSL ใหม่โดยยึดฟิลด์ของ entity และรูปแบบที่แนะนำในปัจจุบัน
- ตรวจหรือแก้ DSL เดิมโดยแยกฟิลด์ของ entity ฟิลด์ที่พบบ่อยใน fixture และฟิลด์เพื่อความเข้ากันได้
- ถ้าเป็นปัญหาการเลือกโหมด เส้นทางงาน หรือข้อสรุปการส่งมอบ ให้กลับไป skill ที่เกี่ยวข้อง
